Every time we get a new idea, we get stuck in a loop of trying to make it perfect before the first move. That first move is the hardest. We're not ready to step forward because something is still missing. Endless preparation.
I got steps to show you.
You read this post, but I didn't start it. Someone else did. Maybe not posting itself, but the whole initiative. The core part was the step before I started. You can read about it in another post, but let's leave this first step for a while.

# Yesterday I did the second step.

I was so lazy about writing Markdown myself and keeping everything needed to maintain this blog that I created an app. Simple one. An app for doing all of that in a UI, without worrying about missing ":" somewhere in the file structure.

Am I lazy? Yes! Am I creative? Maybe. Did I move forward? For sure.

... and it was easy.

# Why is it easier from the second step?

Because of the basics that are already done. It's like building a sand castle. The hardest step is getting sand from the beach and preparing a place. Right after that, building a single wall, tower, and window in that wall is easier because we already have something.

# What are we usually missing?

We almost always start from the n-th step. The first few steps are done, but we don't see it. Explaining it by example,e I would say: Let's build a new desk. With two shelves! With automated height change! With cable extensions and a built-in flower pot! When you stop here and take a look carefully at that idea, you will see that you can already buy legs with automated height control for that desk. Even if we decide to build it from scratch, wires, components, bearings, and threaded rods are available.
